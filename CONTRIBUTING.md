# Contributing

## Setup

You need Go (the version in `go.mod`), Node 24, [Task](https://taskfile.dev) and the
[Wails v3 CLI](https://v3alpha.wails.io/). Then:

```sh
task dev        # the app with live reload
```

`npm start` in `frontend/` runs the UI alone in a browser against an in-memory fake backend, and
`npm run storybook` shows every component in every state.

## Before you send a change

```sh
task check      # formatting, lint and tests, as CI runs them
```

The Storybook tests (`npm run test-storybook` in `frontend/`) run each story's `play` function and fail on
accessibility violations; CI runs them too.

When a Go DTO changes, run `task bindings`; `api/bindings-check.ts` fails the build until `api.ts` matches. When a
view in `internal/view` changes, run `task fixtures` to regenerate the stories' sample data. Commit what both
produce.

## Where things go

The backend computes; the frontend shows. Day states, totals, to-dos and what may be edited are decided in Go
(`internal/view`, `app/`), and the frontend formats and lays them out.

`frontend/src/app/`:

| Folder | Holds |
| --- | --- |
| `api/` | The `Api` interface, the Wails implementation, the in-memory `FakeApi`; test data in `api/testing/` |
| `shell/` | The window: sidebar, toolbar, status bar, shortcuts, the list of panes |
| `pages/` | One folder per page, routed from `app.routes.ts` |
| `ui/` | Components that take inputs and emit outputs, with no store or API of their own |
| `state/` | The `ShellStore` and other injectable state |
| `shared/` | Pure functions, pipes and constants |
| `i18n/` | `en.json`, `hu.json` and the `t` pipe |

A component is a `.ts` file with its template in a `.html` file beside it, and a `.css` file when it has styles of its
own. Every component in `ui/`, `pages/` and `shell/` has a `.stories.ts` (a spec checks this).

Text the user sees goes through i18n, in both languages. A message from the backend is a code in
`internal/core/messages.go` with its English text, and `msg.<code>` in both JSON files; a Go test checks they match.

`frontend/libs/ui/` is generated by spartan-ng and `frontend/bindings/` by Wails: they are not linted or formatted by
hand.
